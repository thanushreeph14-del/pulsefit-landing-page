
# PulseFit — Responsive Product Landing Page

## About the Project

PulseFit is a responsive smartwatch product landing page
created as part of the Web Development Week 02 Minor Project.

The project demonstrates modern web layout techniques,
product presentation and responsive design.

## Features

- Responsive navigation bar
- Hero section with product image and call-to-action buttons
- Product features displayed using CSS Grid
- Benefits section using Flexbox/Grid layouts
- Testimonial cards
- Product pricing and enquiry section
- Footer with contact and social links
- Responsive tablet and mobile layouts

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Tailwind CSS CDN

## Project Structure

pulsefit-landing-page/
├── index.html
├── style.css
└── README.md

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Make sure you have an internet connection for Tailwind
   CDN and the externally hosted product images.

## Learning Outcomes

This project helped me practise semantic HTML, CSS styling,
responsive breakpoints, Flexbox, CSS Grid and landing page design.
